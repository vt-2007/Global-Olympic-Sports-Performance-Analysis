## 📌 Project Overview

**Global Olympic Sports Performance Analysis** is a data visualization project developed using **Tableau** to analyze Olympic sports performance, medal achievements, and country-wise participation.

The project transforms Olympic data into meaningful visual insights, helping users understand medal distributions, compare country performances, and explore trends across different Olympic editions.

## 🎯 Objectives

- Analyze Olympic medal achievements across countries.
- Compare Gold, Silver, and Bronze medal distributions.
- Identify top-performing countries based on medal counts.
- Explore medal distribution across different sports.
- Analyze participation and performance across available Olympic editions.
- Present meaningful insights through interactive Tableau dashboards.

## 🛠️ Tools & Technologies

- **Tableau Public** — Data visualization and interactive dashboards
- **Microsoft Excel / CSV** — Dataset preparation and data handling
- **Data Visualization** — Charts, graphs, comparisons, and analytical insights

## 📂 Dataset

This project uses the **120 Years of Olympic History: Athletes and Results** dataset from Kaggle.

- **Source:** [120 Years of Olympic History — Kaggle](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)
- **Dataset Contents:** Historical Olympic athlete records, participating countries, sports, events, and medal results.
- **Purpose:** To analyze Olympic medal distributions, compare country-wise performance, and explore participation and performance trends across Olympic editions.



## 📊 Key Features

- **Medal Analysis:** Visual comparison of Gold, Silver, and Bronze medals.
- **Country Performance:** Country-wise medal comparisons and rankings.
- **Sports Analysis:** Explore medal distributions across different sports.
- **Participation Analysis:** Examine country and athlete participation using available data.
- **Interactive Dashboards:** Explore visualizations using available filters.
- **Performance Trends:** Analyze Olympic results across different editions.

## 📈 Project Workflow

1. Collect and prepare the Olympic dataset.
2. Import the dataset into Tableau.
3. Clean and organize data fields where necessary.
4. Create charts and visualizations to analyze Olympic performance.
5. Combine visualizations into interactive dashboards.
6. Develop a Tableau Story to communicate key findings.
7. Interpret the visualizations and summarize important observations.

## 💡 Expected Outcomes

- Understand Olympic medal distributions across countries.
- Compare country-wise performance and medal achievements.
- Identify patterns in sports participation and medal distribution.
- Explore performance trends across available Olympic editions.
- Demonstrate how data visualization can simplify complex datasets and support data-driven insights.
